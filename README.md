### What is Cube Boot?

Cube Boot is a multiprotocol bootloader and boot manager


### Supported architectures
* IA-32 (32-bit x86)
* x86-64
* aarch64 (arm64)
* loongarch64

### Supported partitioning schemes
* MBR
* GPT
* Unpartitioned media
